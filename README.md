Upload the contents of this ZIP directly to the root of the GitHub repository.

Required structure:

- index.html
- about.html
- services.html
- industries.html
- insights.html
- resources.html
- partners.html
- contact.html
- assets/style.css
- assets/script.js
- assets/logo.png
- assets/founder.png
- assets/banner.jpg

Do not keep duplicate CSS, JavaScript, or image files at the repository root.
